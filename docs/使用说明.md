# 使用说明

一个 Spring Boot + LangChain4j 的小项目：填学生档案，系统检索本地岗位资料，生成大学四年成长规划（流式输出）。

不需要 Redis、MySQL、登录。

---

## 1. 准备

- JDK 17
- 首次构建能联网：Maven 会把依赖下载到本机 `C:\Users\你的用户名\.m2\repository`，之后都读缓存
- 一个 OpenAI 兼容服务的 API Key（如智谱 GLM、DeepSeek）

> 仓库里只有源码和 `pom.xml`，依赖不提交。国内网络建议先看第 10 节配一次镜像，首次构建会快很多。

---

## 2. 配置 Key 并启动

**第一步：改 Key**

打开 `src/main/resources/application.yaml`，把两处 `api-key` 改成你的 Key：

```yaml
api-key: sk-你的Key
```

`chat-model` 和 `streaming-chat-model` 下面各一处，都改。

**第二步：启动**

两种方式选一种：

- **IDEA**：点 `CareerAgentApplication` 旁边的 Run 按钮。
- **命令行**：项目根目录执行 `.\mvnw.cmd spring-boot:run`（macOS / Linux 用 `./mvnw`）。

控制台出现 `Tomcat started on port 8080` 就成功了。

浏览器打开：<http://localhost:8080/>

> 不需要自己装 Maven：`mvnw`（Maven Wrapper）会自动下载一套 Maven 到本机，再交给它构建。

---

## 3. 页面怎么用

1. **顶部填档案**：专业、年级、目标岗位（必填）、已掌握技能、每周时间、发展方向。
2. 点 **“生成成长规划”**：系统检索岗位资料，输出六段式规划。
3. 点 **“修改学习条件”**：改目标岗位 / 每周时间，同一段对话里重新规划。
4. 底部输入框可以继续追问，例如“那先学哪个？”。
5. 左侧可以新建对话、切换对话、删除对话（只删浏览器记录）。

## 5. 加自己的岗位资料

位置：`src/main/resources/content/jobs/`，只读 `.txt`。

写法：

```text
岗位名称：Java 后端开发工程师
公司：某公司
来源：https://原始链接
日期：2026-10-23

岗位职责
参与后端接口开发……

任职要求
熟悉 Java、Spring Boot……
```

规则只有三条：

1. **第一段**写岗位名称、公司、来源等信息，作为“公共头”；
2. 后面每段之间**空一行**，每段会被单独检索；
3. 一个文件可以放多个岗位，岗位之间用单独一行 `====` 隔开。

保存成 UTF-8，重启应用生效（启动时会重新向量化）。

格式细节见 `docs/岗位资料格式说明.md`。

## 6. 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 页面提示“请求失败” | 后端没启动，或 Key 没设 / 无效；看控制台日志 |
| 回答里说“资料不足” | `content/jobs` 下没有 txt，或文件没按格式写 |
| 刷新后聊天记录还在 | 正常，记录存在浏览器 `localStorage` |
| 重启后 AI 不记得上文 | 正常，模型上下文只在内存里；浏览器记录还在 |
| 端口 8080 被占用 | 关掉占用程序，或改 `application.yaml` 的 `server.port` |
| 第一次启动很慢 | 要下载依赖和本地向量模型，之后会快 |

---

## 7. 跑测试 / 打包

IDEA 里：右键测试类（如 `CareerAgentControllerTest`）→ Run，就够了。

需要用命令行时（项目根目录）：

```powershell
.\mvnw.cmd clean test       # 跑单元测试
.\mvnw.cmd clean package    # 打包，jar 在 target/ 下
.\mvnw.cmd spring-boot:run  # 启动应用
```

第一次执行会下载 Maven 本体和依赖，之后都走本地缓存。

## 9. 常见修改：改哪里

| 想改什么 | 去哪里改 | 说明 |
| --- | --- | --- |
| 每次检索几段资料 | `RagConfig.java` 的 `.maxResults(5)` | 当前 16 段资料，建议 5；资料变多后可试 6~8 |
| 过滤低相关段落 | `RagConfig.java` 加 `.minScore(0.4)` | 需要实测，设太高会出现“资料不足” |
| AI 回答太长/太短 | `system.txt` 的【长度与格式】 | 改字数、每部分条数 |
| AI 回答格式 | `system.txt` 的【回答结构】 | 六个标题和顺序 |
| 多轮记忆长度 | `CommonConfig.java` 的 `.maxMessages(20)` | 数字越小越省 token |
| 模型 / Key | `application.yaml` 的 `chat-model`、`streaming-chat-model` | 两处保持一致 |
| 换个模型服务 | `application.yaml` 的 `base-url`、`model-name` | 重启生效 |
| 端口 | `application.yaml` 加一行 `server.port: 8081` | 默认 8080 |
| 岗位资料 | `content/jobs/*.txt` | 第一段写来源，空行分段，`====` 分多岗位 |
| 页面文案 / 按钮 | `static/index.html` | 直接改 HTML / JS |
| 日志太吵 | `application.yaml` 的 `logging.level` | 项目默认未开 debug |

> 改了 Java、`system.txt`、`application.yaml` 都要重启应用才生效；只改 `index.html` 刷新页面即可。

## 10. 依赖、镜像与离线构建

依赖只在 `pom.xml` 里声明（版本由 Spring Boot 的 BOM 统一管理），**不提交到 git**。首次构建时 Maven 从中央仓库下载到本机 `C:\Users\你的用户名\.m2\repository`，之后都读这份缓存；缓存可以随时删，删了重新下就行。

### 配镜像（国内建议做一次）

新建或编辑 `C:\Users\你的用户名\.m2\settings.xml`：

```xml
<settings>
  <mirrors>
    <mirror>
      <id>aliyun</id>
      <mirrorOf>central</mirrorOf>
      <url>https://maven.aliyun.com/repository/public</url>
    </mirror>
  </mirrors>
</settings>
```

保存后在 IDEA 的 Maven 面板点刷新按钮即可生效。

### 完全没网怎么办

1. 在有网的机器上执行 `.\mvnw.cmd dependency:go-offline`，把依赖下全；
2. 把 `C:\Users\用户名\.m2\repository` 整个目录拷到对方机器的相同位置；
3. 对方执行 `.\mvnw.cmd -o clean package`，`-o` 表示只用本地缓存、不联网。

### 只想运行，不想构建

把 `target/career-agent-0.0.1-SNAPSHOT.jar` 上传到 GitHub Releases，别人下载后：

```powershell
java -jar career-agent-0.0.1-SNAPSHOT.jar
```

这个 jar 自带全部依赖（`BOOT-INF/lib`），只要装了 JDK 17 就能跑，不需要 Maven、不需要联网。发布前用 `.\mvnw.cmd clean package` 重新打一次包，保证 jar 和源码一致。

## 11. 换成别的模型服务

改 `application.yaml` 里的两处 `chat-model` 和 `streaming-chat-model`：

```yaml
base-url: https://你的服务地址
api-key: 你的Key
model-name: 你的模型名
```

保存后重启应用。
