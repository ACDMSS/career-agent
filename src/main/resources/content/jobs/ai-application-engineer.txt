岗位职责
基于大模型 API 开发业务应用：对话、检索增强、结构化输出、工具调用。
设计提示词和评测用例，持续改进回答质量与稳定性。
处理文档解析、切分、检索和上下文组装等应用侧工程问题。
与业务方协作，把模糊需求拆成可验证、可上线的 AI 功能。

任职要求
熟悉至少一门后端语言（Java 或 Python），能开发并调试 HTTP 服务。
理解大模型基本概念：上下文窗口、提示词、温度参数、流式输出。
了解 RAG 的基本流程：文档切分、检索、排序、在回答中引用来源。
具备基本的评测意识：能设计测试问题集，判断效果好坏并定位原因。
能处理 JSON 解析、接口联调、日志与异常。

加分项
使用过 LangChain4j、LangChain 等应用框架。
了解 embedding 与向量检索的适用场景及成本。
有多轮记忆、工具调用（Agent）的实践经验。
了解成本与延迟优化：缓存、批处理、模型选择。
