岗位职责
参与业务系统后端模块的设计与开发，按需求完成接口、数据处理和联调。
编写可维护的 Java 代码，补充单元测试，定位并修复常见缺陷。
参与数据库表结构设计与 SQL 优化，保证接口的稳定性和响应速度。
与前端、测试、产品协作，参与需求评审和技术方案讨论。

任职要求
熟悉 Java 基础：集合、异常、并发基础、JVM 基本概念。
熟悉 Spring Boot / Spring MVC，理解依赖注入、AOP、事务的使用场景。
熟悉 MySQL，能写多表查询、理解索引和基本的 SQL 优化。
了解 HTTP 与 RESTful 接口设计，能使用 Git 进行多人协作。
具备基本的调试能力：会看日志、会用断点和单元测试定位问题。

加分项
了解 Redis 缓存、消息队列等中间件的基本使用场景与取舍。
了解 Linux 常用命令与基本的部署流程。
有完整的项目经历：需求分析、接口设计、测试、上线与复盘。
了解 Docker、CI/CD 的基本概念。
