岗位名称：大数据后端开发工程师（数据平台/管道方向）
公司：广东亿迅科技
岗位方向：backend/data-infrastructure
来源：https://eshore.zhiye.com/zpdetail/151246101
日期：2026-09-14

岗位职责
数据仓库与ETL开发：参与数据仓库的分层架构设计与维度建模，负责数据接入、清洗、转换（ETL）流程的开发与维护，保障数据产出的准确性与时效性。
大数据平台开发：参与大数据服务平台的建设，使用流式计算（如Flink）或OLAP引擎（如ClickHouse/Doris）对传统业务流程进行改造，提升数据处理效率。
数据服务与支撑：为业务分析、产品迭代及BI报表提供高质量的数据支撑，包括数据查询、指标计算、数据接口开发等。
数据治理与优化：参与数据治理工作，制定数据标准管理，元数据管理，数据质量管理等；参与数据质量监控、数据血缘维护及任务性能调优；及时响应复杂的数据分析需求，协助团队保障数据管道的稳定与高效运行

任职要求
计算机、软件工程、大数据技术等相关专业本科在读。
熟练掌握一门或多门编程语言，如Java、Python、shell（加分），具备扎实的计算机基础（数据结构、算法、操作系统、网络）。
精通 SQL 语法，熟悉 MySQL、PostgreSQL、dameng等关系型数据库，有 Hive SQL、Spark SQL 等大数据SQL编写经验者优先。
熟悉 Hadoop、Hive、Spark、Flink、Kafka、HBase、ClickHouse/Doris 等主流大数据组件的基本原理与应用场景。
熟悉 Linux 操作系统及常用命令，了解 Shell 脚本编程；了解数据集成，能使用大数据中台完成数据集成任务；
有数据仓库建设、ETL开发、数据分析或大数据平台相关实习/项目经验者优先。
具备强烈的责任心、团队协作精神，以及优秀的逻辑思维和问题解决能力

加分项
了解Kafka或其他消息队列的基本模型（生产者、消费者、Topic、分区）。
接触过Hadoop/Spark生态的任一组件（哪怕是课程实验级别）。
使用过Docker搭建过包含多个组件的本地开发环境。
了解数据管道中“至少一次/恰好一次”语义的基本区别。
